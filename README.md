# Tharun Ballal M — Portfolio

Responsive single-page portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
Replace `your.email@example.com` in `index.html` with your email address. Add your GitHub, LinkedIn, projects and resume links when ready.

## Deploy
Enable GitHub Pages in Settings → Pages and select the `main` branch / root folder.

The supplied personal emblem is included as an SVG asset and used in the header, footer and browser tab.
